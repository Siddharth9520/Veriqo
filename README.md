# Veriqo

**Veriqo** is an Autonomous AI QA Engineer platform designed to explore web applications, execute exploratory and regression test flows, collect evidence, report defects, and independently verify issues.

## Project Structure

- `backend/`: FastAPI backend service, SQLite database with SQLAlchemy 2.0 models, health/readiness endpoints, and core configuration.
- `frontend/`: (Planned) Next.js frontend with TypeScript and Tailwind CSS.
